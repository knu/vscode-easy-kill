# Easy Kill

**Easy Kill** is a Visual Studio Code-compatible extension that lets
you select and copy things easily.  This is a port of
[*easy-kill*](https://github.com/leoliu/easy-kill) for Emacs.

## What This Extension Does

This extension allows users to:

- Use **Easy Kill: Copy** as a drop-in replacement for standard copy
- Select or copy with intelligent selection when nothing is selected
- Expand or shrink selections interactively across 30+ object types
- Duplicate selections quickly in either direction
- Use Vim-friendly character search with f/t-style selection

All operations are performed **entirely within the editor buffer**.

---

## Security & Privacy

- This extension **does not execute external commands**
- It **does not access the network**
- It **does not collect telemetry or user data**

All behavior is limited to editor text manipulation using the VS Code API.
